# Field notes

Impressions from real work with local models. They are valuable and they are not
measurements: no controlled task set, no repeats, no scorer.

Rules:

- Date every note.
- Say what the work was (task type, rough size, how long it ran).
- Say what happened, including when a model failed where another succeeded.
- Do not rank. Do not give a score. Do not copy a note's conclusion into a results table.
- If a note later gets measured, link the measurement and say whether it agreed.

Template — copy to `YYYY-MM-DD-short-title.md`:

```
Date:
Model(s) and build:
Setup (runtime, quant, context, settings):
The work:
What happened:
What I did not check:
```
