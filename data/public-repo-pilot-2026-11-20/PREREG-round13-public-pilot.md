# Round 13 plan: public real-repository pilot on Mercury 3 (written 2026-11-20 BEFORE any run)

Why: the kits and the 38-task bench are synthetic and mostly at the ceiling; the question that matters is whether the closing-line rule changes **real work**. The private pilot (own repositories) cannot be sent to a provider that trains on prompts (Inception's policy), so this pilot uses 20 cases from six **public** repositories (`screen-B/real-bench/PUBLIC-FROZEN.md`, sha256 of the case file recorded there). Mercury 3 is fast and cheap; it is also the model where the kits showed no effect, so this run tests safety and cost on real work, not the closing-line behaviour.

- Model `mercury-3` (Inception API), Forge agent, window 64,000, at most 60 tool calls per case, concurrency 1, profile auto. Arms: control (`dist/lib.js`) and `p3f` (`dist-finish/lib.js`), alternating order by pass (control first on even passes), **2 passes per arm = 40 case-runs per arm**, seed offsets 0 and 1.
- A case ends in one verdict: `solved` (the fix's hidden tests pass), `overfit`, `blocked`, `budget` (60 calls used), `failed`, `harness_error`. `harness_error` rows are redone once; every other verdict is a real outcome and counts (see CORRECTIONS 13).
- **Primary comparison (descriptive, no claim of significance planned):** solved count `p3f` against control over the 2 passes, paired by case; the number of cases solved by both, only by one arm, by neither; the same-arm pass-to-pass swing (a case solved in one pass and not in the other of the same arm) is reported first because it bounds what a difference can mean.
- **Safety criterion fixed now:** `p3f` is not called safe on real work if its solved total is more than 3 below control's of 40, or if `harness_error`/crash rows are higher. With 40 runs per arm this cannot detect a small effect; it can only exclude a large loss, and the text will say so.
- Cost: output tokens and input tokens per arm (ratio of totals, per-case bootstrap 95 %), and tool calls.
- Spend: estimated from token counts at the list price (0.20 input / 0.70 output USD per M, no cache discount, so an upper bound); the driver stops at 10 USD estimated. A first control pass is the harness check; if the harness itself fails (not the model), it is fixed and restarted and the fault is recorded.
- Caveat fixed now: public repositories can be in the model's training data; fix commits dated on or after 2026-09-15 are the only protection.
