File: `real-bench/tasks-public.mjs`, sha256 e3fb4a977252397ed71225a9650c9183f7f4873292aa631f11d439ed6f0d6b19. 20 cases from six public GitHub repositories (fb55/htmlparser2, felladrin/MiniSearch, dyoshikawa/rulesync, nansen-ai/nansen-cli, agentclientprotocol/claude-agent-acp, solidjs/solid-router), fix commits dated on or after 2026-09-15, found by `public-bench/scan_public.py`, validated by `public-bench/validate_public.mjs` (the fix's own tests fail on the parent on real assertions and pass on the fix, each twice), filtered for missing-symbol failures, chosen by a sha256 hash order with a quota per repository, then symptom reports written by hand from the observed failure and the behaviour the tests demand (no commit message, no test name, no fix code; `public-bench/make_cases.py`).
