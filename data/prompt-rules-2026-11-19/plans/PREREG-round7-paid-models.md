# Round 7 plan, written 2026-11-19 BEFORE any round-7 run

Owner's decision (2026-11-19): run the shortlist of cheap paid OpenRouter models; the assistant proposed a spend cap of 4 USD and the owner said to run them all. The cap is enforced by the driver: before every request batch the key's reported spend is read, and the driver stops when it reaches 4.00 USD (the key itself also carries a 5 USD monthly limit).
Models, in this order, each id fixed in the request (the logging proxy records the model and provider that answered): `qwen/qwen3.8-27b`, `qwen/qwen3.8-flash`, `deepseek/deepseek-v4.1-flash-1017`, `openai/gpt-oss-120b`, `qwen/qwen3.7-flash`, `z-ai/glm-4.7-flash`, `z-ai/glm-5.3-flash`, `anthropic/claude-haiku-5.5`, `qwen/qwen3-coder-next`. Why these: same base as the local 27B and the Pi adapter (`qwen3.8-27b`), the family of Strata (`qwen3.8-flash`), the cheapest strong agentic models (DeepSeek, GLM), the common open-weights reference (`gpt-oss-120b`), a small frontier ceiling (Haiku), a code-specialised model (`qwen3-coder-next`).
Design per model: kits P3b and P3c; arms control and `p3f`; 16 repetitions per arm per kit (64 runs); arms interleaved per repetition with alternating order; window 64,000; seed = repetition. Same instruments as rounds 2-6.
Runs interrupted by an endpoint error are moved to `interrupted/` and redone later, never counted. A model that completes no run in the first pass is reported as unusable and skipped.
Primary comparison per model: closing-line rate of `p3f` against control, pooled over both kits, Fisher exact two-sided. Nine models are looked at: a claim for one model needs p < 0.0056 (Bonferroni over nine); smaller p-values are suggestive only. Secondary: tasks solved (must not drop), output tokens per completed run (ratio and bootstrap interval), model calls, actual cost per model from the key's spend.
Caveats fixed now: hosted providers may serve a quantised or differently configured version and this is not controlled; reasoning tokens are billed as output; results do not transfer to the local quantised models.
